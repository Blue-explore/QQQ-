# QQQ 期权策略 + 新闻 Agent + 五年回测

一个完整可运行、可复现的量化交易研究项目：包含**备兑看涨（Covered Call，策略一）**
与**趋势回踩买 Call（策略二）**，其中策略一的条件 2 由一个**新闻分析 Agent** 判定。

> **当前配置（用户最终定稿）**：IV 口径**只保留相对口径**——
> `VXN ≤ 过去 252 个交易日 VXN 的 10 分位`（固定绝对阈值已移除）；
> **策略一 + 策略二一起跑**（`strategies = "both"`）；
> 策略二每次信号**买 10 张**；
> 持仓 **Delta 跌破 0.5 且基本面没问题 → Roll 到 Δ0.6 / 365 天**，张数保持 10；
> 初始资金 **$200,000**（10 张一年期 call + 100 股备兑底仓同时占资）。

## 一、策略定义（严格按需求实现）

### 策略一：Covered Call —— 从不裸卖

卖出一张**约一周（7 天）、Delta = 0.2** 的 call，必须**同时**满足三个条件：

| # | 条件 | 实现 |
|---|---|---|
| 1 | 股价刚冲完一波？ | 每个交易日算 `r5(t) = close[t]/close[t-5] - 1`；取**过去 5 年（1260 个交易日）**的 r5 从大到小排，**第 126 个**作为门槛；当日 `r5 >= 门槛` 即命中（前 10%）。门槛只用 t 之前的历史计算，无前视偏差 |
| 2 | 有没有短期技术阻力压着？ | **新闻 Agent**：读取 GDELT 相关新闻，判定是否存在技术阻力（前高/均线压制/超买/滞涨/双顶…）；**若为人为动作引起的市场变动则不算**（美联储、关税、财报、地缘、监管等） |
| 3 | IV 是否够低？ | **`VXN ≤ 过去 252 个交易日 VXN 的 10 分位`**（CBOE 纳指100隐含波动率指数）。即「波动率处于近一年最低的 10% 才算低」；门槛每天按滚动窗口重算、**不含当日**，无前视偏差。用户最终定稿，固定绝对阈值已移除 |

**「从不裸卖」是引擎级硬约束**，不是一句注释：

- `Portfolio.ensure_covered()` 在开空 call 前校验 `shares >= contracts × 100`，不足则**先买入足额 QQQ 现货**；
- 现金不够时**直接拒绝开仓**并记录 `BLOCKED_NAKED` 事件；
- 开仓后还有 `assert` 二次断言；
- 单元测试 `test_all_short_calls_covered` 逐笔核对两种运行模式下每一笔 `SELL_CALL` 当日持股 ≥ 100。

被行权时按行权价 K 交割 100 股；价外到期则保留全部权利金。

### 策略二：买入 Call

每次信号买入 **10 张 Delta = 0.6、约一年（365 天）** 的 call（用户三次修订，原为 1 张），
必须同时满足：

| # | 条件 | 实现 |
|---|---|---|
| 1 | 牛市趋势 | **任一成立即可**：① 策略一近 3 个月（63 个交易日）触发 ≥ 3 次；② 近一年（252 个交易日）最大回撤 ≤ 10% |
| 2 | 单日跌幅 > 1% | `close[t]/close[t-1] - 1 < -0.01` |

策略一与策略二**联动**：策略一的触发标记驱动策略二的牛市条件 ①。

#### Delta Roll（用户三次修订）

> 「如果策略二基本面没问题，但 Delta 掉到了 0.5 以下，Roll 到 Delta 为 0.6」

| 项 | 实现 |
|---|---|
| 触发条件 | 持仓当前 `Delta < 0.50`、剩余期限 ≥ 30 天、且「基本面没问题」 |
| **基本面判定** | 复用新闻 Agent：当日及之前的新闻里若出现**业绩暴雷/指引下调/评级下调/欺诈/诉讼/召回/裁员/减值/违约**等负面词 → 不 Roll；无负面词或无新闻 → 默认放行。刻意**不复用** C2 的「人为动作」词表，因为美联储/关税等宏观事件不等于公司基本面恶化 |
| 执行 | 平掉旧仓（按盯市价）→ 重新买入 10 张 Δ0.6 / 365 天 call，行权价按当时 S 反解 |
| 保护 | 换仓前校验现金，避免「平了旧仓却开不出新仓」；临近到期不滚；每次 Roll 后冷却 1 天 |
| 日志 | `ROLL_CLOSE` / `ROLL_OPEN` / `ROLL`，另有 `ROLL_BLOCKED_CASH`、`ROLL_SKIPPED`（基本面不合格） |

⚠️ **本次回测的诚实说明**：当前相对口径下两次买 call 的 Delta 最低只到 0.56，
从未跌破 0.5，故 **0 次 Roll、0 次基本面检查**，这条规则在本样本内没有产生实际影响。
Roll 与基本面判定的逻辑本身由合成场景单元测试验证（正常放行 / 负面新闻拦截两条路径均通过）；
若要让它在真实回测里生效，需补齐 GDELT 新闻或接入真实 LLM 后端。

### 运行模式（可切换）

`config.py` 的 `BacktestConfig.strategies` 或 CLI `--strategies`：

| 值 | 行为 |
|---|---|
| `both`（**当前默认**） | 两个策略都跑，策略一触发次数会喂给策略二的牛市条件 ① |
| `cc_only` | 只执行策略一。策略二**不评估、不开仓**，组合里不会出现 Δ0.6 的一年期 long call |
| `lc_only` | 只执行策略二 |

「触发」与「实际成交」分开统计：条件满足即算触发，但同一时间最多持有 1 张空 call /
1 个 long call 批次（1 批 = 10 张），因此实际开仓笔数少于触发次数。

### 期权定价

Black-Scholes（含连续股息率 q），`VXN × 0.85` 作为 QQQ 期权年化 IV（VXN 是指数级 IV，
ETF 期权通常略低）；用二分法反解目标 Delta 对应的行权价，按 **1 美元整数档**取整。
含滑点（权利金 2%）、每张 $1 手续费、股票买卖 5bp 费用。

## 二、数据事实：相对口径下 C3 真正起筛选作用

系统现在只有**一种** IV 口径：`VXN ≤ 过去 252 个交易日 VXN 的 10 分位`。
固定绝对阈值（历史上依次试过 `>50` / `<50` / `<30`）已按用户要求从代码与配置中移除。

| 年份 | VXN 最大 | 当年滚动 10 分位门槛均值 |
|---|---|---|
| 2021 | 39.6 | 19.68 |
| 2022 | 41.4 | 21.02 |
| 2023 | 29.4 | 21.89 |
| 2024 | 35.1 | 16.51 |
| 2025 | 43.2 | 17.20 |
| 2026 | 38.3 | 18.83 |

近五年回测区间（2021-11-08 ~ 2026-11-06，共 1255 个交易日）VXN 中位数 22.51、
最小 13.59、最大 43.25。滚动 10 分位门槛在 **16.20 ~ 26.80** 之间浮动（不是常数）：
2022 年波动整体偏高，门槛自动抬到 ~21；2024 年整体平静，门槛降到 ~16.5。
相对口径在 **217 / 1255 天（17%）** 成立，确实筛掉了大部分交易日。

因此策略一候选日 = C1（5 日涨幅前 10%，132 天）∩ C3 = **26 天**，
最终是否触发还取决于新闻 Agent 的 C2 判定。

解读：10 张一年期 Δ0.6 call 是强方向性多头，在上涨段把收益放大到 **+104.25%**
（基准 +64.82%），同时把年化波动推到 14.14%；相对口径只在 IV 最平静时开仓，
**最大回撤 16.76%，不到基准 35.62% 的一半，夏普 0.94 也明显优于基准 0.46**。

- **0 次 Roll 是正确行为**：两次买 call 的 Delta 最低只到 0.56，从未跌破 0.5 触发线。
  Roll 逻辑本身由合成场景单元测试验证（`test_roll_logic_still_works_on_synthetic_position`）。
- **触发 ≠ 成交**：策略二条件触发 27 次但只开 2 批，因为一年期 call 长期占仓且上限 1 批；
  报告已把「触发次数」与「实际开仓批数/张数」分开列示。
- **基本面检查 0 次**：因 Delta 从未跌破 0.5，Roll 前置检查根本没被触发，
  不是「检查后放行」。报告里对这一路径有专门说明。

⚠️ 初始资金 $200k 是必要的：100 股备兑底仓（$35k~$72k）+ 10 张一年期 call
（$35k~$81k）同时占资，Roll 还有换仓净支出；资金不足时会记录 `ROLL_BLOCKED_CASH`。
这是真实资金约束，不是程序限制。

## 三、新闻 Agent 设计

`agent/news_agent.py`

```
NewsAgent.analyze(as_of, md, idx, r5, vxn)
   │
   ├─ NewsProvider（CachedGDELTProvider）
   │    读 data/cache/gdelt_news.json，只取 seendate <= as_of 的新闻（杜绝前视）
   │
   ├─ Classifier
   │    ├─ RuleClassifier（默认，离线可复现）
   │    │    取最相关 TOP 12 条头条 → 统计「人为动作」与「技术阻力」独立证据条数
   │    │    → 人为动作占主导 ⇒ HUMAN_ACTION（按需求「不算」）
   │    │    → 技术证据占主导 ⇒ TECHNICAL_RESISTANCE
   │    │    → 都无信号 ⇒ 价格结构代理（50 日均线压制 / 前期套牢区 / RSI 超买 / 冲高滞涨）
   │    └─ LLMClassifier（可选，openai / anthropic）
   │          SYSTEM_PROMPT 固化判定标准，强制 JSON 输出；失败自动回退规则分类器
   │
   └─ NewsVerdict(has_resistance, human_caused, verdict, evidence, reasoning, source)

NewsAgent.fundamentals_ok(as_of)          ← Roll 前置检查（用户三次修订新增）
   │
   ├─ 读同一份新闻缓存，只取 seendate <= as_of
   ├─ 命中 fundamental_bad_keywords（业绩暴雷/指引下调/评级下调/欺诈/诉讼/召回/
   │   裁员/减值/违约等）⇒ ok=False，不 Roll
   └─ 无负面词或无新闻 ⇒ ok=True（默认放行，source=no-news-default-ok）
        → FundamentalVerdict(ok, n_headlines, bad_hits, source)
```

**只对候选日调用 Agent**（C1 与 C3 同时成立的日子），避免 1260 个交易日逐日调用 LLM。
相对口径下候选日 26 天，回测里 Agent 实际调用 **26 次**；
由美联储 / 关税 / 财报 / 地缘等人为动作驱动的反弹会被判定为 `HUMAN_ACTION` 而否决，
体现了「人为动作不算」这条硬约束。

`fundamentals_ok` 与 C2 用的是**不同词表**：C2 的「人为动作」包含美联储/关税等宏观事件，
而 Roll 只关心公司/基本面恶化，两者不可混用。

接真实 LLM：

```python
from qqq_options.agent.news_agent import NewsAgent, LLMClassifier
agent = NewsAgent(classifier=LLMClassifier(api_key="sk-..."))  # 需 openai 包
```

抓取新闻（GDELT 限流较严，脚本自带 12s 间隔 + 429 指数退避 + 断点续跑）：

```bash
python -m qqq_options.agent.fetch_candidates   # 26 个候选日
```

## 六、已知局限（研究用途，不构成投资建议）

1. **IV 用 VXN 近似**：VXN 是纳指100**指数**期权 IV，不是 QQQ 单个期权链的 IV；
   用固定 0.85 系数缩放是简化处理，未使用真实期权链（需要付费数据源）。
2. **波动率曲面简化**：未建模 skew / term structure，一周与一年期用同一 IV 缩放。
3. **行权价整数档**：按 1 美元取整，实际 Delta 与目标 0.2/0.6 有约 ±0.01 偏差。
4. **到期按自然日**：未精确对齐真实期权到期日（通常为周五/月度第三个周五）。
5. **未考虑**：保证金占用、分红税、流动性冲击、盘中止损、组合再平衡。
   Delta Roll 已实现，但只按「平旧仓 + 开新仓」的净额换仓处理，未建模真实期权组合订单的
   成交价差与腿间风险。
6. **新闻样本有限**：GDELT 限流导致部分窗口缺失，缺失日 Agent 走价格结构代理，
   报告中 `source` 字段会如实标注 `price-structure` 而非 `gdelt-rule`。
7. **只有相对口径，无绝对阈值对照**：历史上试过的 `>50` / `<50` / `<30` 已全部移除，
   无法再与固定阈值结果做同区间对照。滚动 10 分位门槛本身随市场波动状态浮动
   （16.20~26.80），对 `iv_lookback_days` 与 `iv_percentile` 两个参数敏感。
8. **触发 ≠ 成交**：连续多日满足条件时，受 `max_open_short_calls=1` 限制只开一张
   （7 天期 call 未到期前不会重复卖）；策略二同理，一年期 call 长期占仓且上限 1 批（10 张）。
   报告已把「触发天数」与「实际成交张数」分别列示。
9. **新闻仍可能不完整**：GDELT 限流下若个别周窗口抓取失败，该日 Agent 回退到
   价格结构代理，`source` 会如实标注 `price-structure`，报告中也会给出两类来源的天数统计。
10. **Roll 与基本面检查在本次回测中 0 次触发**：相对口径下 Delta 从未跌破 0.5，
    Roll 前置检查根本没被走到，因此「基本面没问题」这条规则**在本样本内未产生任何实际影响**。
    逻辑本身由合成场景单元测试验证（正常放行 / 负面新闻拦截两条路径均通过）。
11. **样本量小**：策略一触发 20 天、策略二只开 2 批、0 次 Roll，
    任何绩效指标都不具备统计显著性，不宜据此下结论。10 张一年期 Δ0.6 call 是强方向性
    多头杠杆，收益放大的同时也会放大波动（本次年化波动 14.14%、最大回撤 16.76%）。
12. **资金占用与初始资金**：100 股备兑底仓 + 10 张一年期 call 同时占资，
    Roll 还有换仓净支出；资金不足时 Roll 会被跳过（记为 `ROLL_BLOCKED_CASH`）。
    初始资金设为 $200k 以留出余量，但这也放大了绝对收益/亏损的规模。
